# Machine Learning Technique to Identify Transit-Shaped Signals

Detecting exoplanets by classifying transit-shaped signals in light curve data using machine learning.

## Overview

This project applies machine learning to identify the characteristic dip in stellar brightness caused by a planet transiting in front of its host star — the transit method used by missions like Kepler and K2 to detect exoplanets.
